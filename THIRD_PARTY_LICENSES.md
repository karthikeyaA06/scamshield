# Third-party licenses

ScamShield's own code is licensed under **Apache-2.0** ([LICENSE](LICENSE), [NOTICE](NOTICE)).
This file lists everything else the project uses: the AI model and runtime, the
Track 1 resources, files bundled in this repository, and every Python package.

**Result of the audit:** every component uses a permissive license (Apache-2.0, MIT, BSD,
ISC, PSF, OFL-1.1 for fonts, CC-BY-4.0 for the skill spec's docs) or MPL-2.0 used
unmodified. **No GPL or AGPL code is used or included.**

Regenerate and re-check the Python list at any time:

```bash
python tools/check_licenses.py
```

## 1. AI model and runtime (not included in this repository)

| Component | What ScamShield uses it for | License | Source |
|---|---|---|---|
| Gemma 4 E4B (`gemma4:e4b`, Hugging Face `google/gemma-4-E4B-it`) | Open-weight model that reasons over the evidence and writes the English/Kannada explanations | Apache-2.0 | [Model card](https://huggingface.co/google/gemma-4-E4B-it), [Gemma docs](https://ai.google.dev/gemma/docs/core) |
| Gemma 4 E2B (`gemma4:e2b`, optional) | Smaller fallback model for laptops with less memory | Apache-2.0 | [Gemma docs](https://ai.google.dev/gemma/docs/core) |
| Ollama | Runs Gemma locally and offline; ScamShield calls its local API | MIT | [github.com/ollama/ollama](https://github.com/ollama/ollama) |

The model weights are downloaded by the user through Ollama. They are not redistributed
here. Check the model card for the current terms before reusing the model elsewhere.
